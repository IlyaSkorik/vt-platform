# Frontend Documentation

## Purpose

Engineering documentation for the frontend: the React 19 + TypeScript + Vite SPA, its feature-sliced structure, design system, state management, and mobile-first, accessible UI conventions.

## Scope

- **In scope:** project structure (feature-sliced), design system (Tailwind + shadcn/ui), state management (TanStack Query for server state), API-client generation, accessibility (WCAG 2.1 AA), performance budgets, and frontend coding standards.
- **Out of scope:** backend/domain logic (see [../backend](../backend/README.md)) and API contracts (see [../api](../api/README.md)).

## Prefix

Documents in this domain use the `FE-` prefix (e.g. `FE-001-project-structure.md`).
